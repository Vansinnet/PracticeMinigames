# PracticeMinigames

A Darktide Mod Framework mod for practising Decode Symbols, Decode Search, Tree Drill, Frequency Matching, and Train Balance from supported hub and training locations.

## Installation

Install DMF, place the `PracticeMinigames` folder in Darktide's mods directory, and add `PracticeMinigames` to `mod_load_order.txt`.

## Download

Download `PracticeMinigames.zip` from the [latest GitHub release](../../releases/latest). Do not use GitHub's source-code archives for installation.
